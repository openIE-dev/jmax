# jmax examples

Runnable example programs for jmax. Each subdirectory is an independent example with its own README explaining what it shows and how to run it.

## Install

```bash
cargo binstall jmax
# or
cargo install jmax
# or download from https://github.com/openIE-dev/jmax/releases
```
