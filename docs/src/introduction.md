# Introduction

**JMax** — JMax — math-native programming language. 2,502 scientific computing functions on the flowG substrate.

This is the official documentation for JMax. The full source code lives in the [private `-core` mirror](https://github.com/openIE-dev/jmax-core); the public release surface is at [openIE-dev/jmax](https://github.com/openIE-dev/jmax).

## The openIE-dev ecosystem

JMax is one of five public openIE-dev projects. All five share a common substrate (flowG) and energy-metering layer (substrate-energy):

- **[flow-g](https://openie-dev.github.io/flow-g)** — the IR + runtime substrate
- **[lux-lang](https://openie-dev.github.io/lux-lang)** — reactive language compiling to flowG
- **[jmax](https://openie-dev.github.io/jmax)** — math-native language
- **[joule-lang](https://openie-dev.github.io/joule-lang)** — energy-budgeted compiled language
- **[jouledb](https://openie-dev.github.io/jouledb)** — energy-metered database
